## Anti-Patterns to Avoid

1. **Don't start 6.5 before Dashboard (6.2)** - Backtest results need the equity curve component
2. **Don't skip 6.1 WebSocket** - Required for all progress tracking
3. **Don't build 6.9 before 6.5** - Optimization runs backtests internally
4. **Don't deploy (6.11) before testing (6.10)** - Critical gate
5. **Don't parallelize 6.12/6.13 with 6.11** - Deployment is the dependency resolver
