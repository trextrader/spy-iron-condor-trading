**Claim 2: Causal Fault Localization for Neural Networks**

**Novel**: YES. Gap analysis found **zero papers** on causal inference for neural fault localization.

**Non-obvious**: Yes. Requires:
- Causal inference (Pearl's do-calculus)

**Useful**: Enables precise root-cause identification, not just correlation.

- Causal ML (Pearl, 2018): Fairness/explainability, NOT fault localization

**Patent Strength**: VERY STRONG. **This is novel research territory.**
